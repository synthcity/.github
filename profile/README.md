Music software, down to the circuit.

We build music tools for the browser and desktop, and share tooling that helps developers reuse DSP across open plugin interfaces.

### For developers

**[Plugin Toolkit](https://github.com/synthcity/plugin-toolkit)** — Rust and C++ starters, CLAP/WebCLAP builds, native AUv2/VST3 adapters and portable audio tests.

We build on [CLAP](https://github.com/free-audio/clap), [WebCLAP](https://github.com/WebCLAP), [Clack](https://github.com/prokopyl/clack) and [clap-wrapper](https://github.com/free-audio/clap-wrapper). Our experimental modular extension is a vendor draft, not an official standard.
